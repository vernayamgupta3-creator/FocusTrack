# 🎯 FocusTrack — Student Productivity Analyzer

FocusTrack is a beginner-friendly Python project that helps students
track their daily study hours, manage tasks, and analyze their weekly
productivity.

## ✨ Features

- Set daily study goals
- Track daily study hours
- View study progress
- Add and complete tasks
- Write daily reflections
- Save data locally
- Analyze weekly study performance
- View productivity charts

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- JSON

## 🚀 How to Run

1. Install Python.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## 💾 Data Storage

The application stores personal productivity data locally in
a JSON file on the user's computer.

## 👨‍🎓 About the Project

FocusTrack is a student project created to practice Python
programming, data analysis, and application development.
